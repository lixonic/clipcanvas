# 0.10.0 release validation — 12 October 2026

The complete source suite passed **123 tests**, including native desktop
workflows and the installed local Tiny speech model, with no skipped tests.
Six focused card/effect UI checks passed after the final popover refinement.
One additional sound-duration caching regression passed with the sound/render
checks, for **124 distinct checks** across the release validation.

The suite uses synthetic clips, WAV/MP3 audio, transparent logos and Unicode
text. It covers transition endpoints/motion/direction/colour, preview/live/
lossless frames, text and image animation, Malayalam captions, matching layer
geometry, mixed entry/exit sounds, seeking, trimming, source hashes, project
migration, recovery, relinking, portable media and single-step editing/undo.

A 200-caption/400-sound-event fixture verifies that the composition has one
additional audio input and Python premixing allocation stays below 4 MB.
Custom sounds with different element durations query their duration once.
Cancellation, muted cues and original-video speech extraction are covered.

Native seek validation checks reuse of one decoder, source trim/speed/fades,
resolution, cross-clip movement, fallback transitions/video overlays, rapid
pointer input, pause/resume and resource cleanup before export. A separate
container timestamp/EOS regression checks that media time stays correct and
the last pending frame cannot move the line back after ending playback.

The [seek benchmark](SEEK-PERFORMANCE.md) measures decode/composition requests
on an original 1080p source. It is separate from the earlier timeline drawing
benchmark. Native UI captures are generated by `tools/qa_effects.py` using a
temporary demonstration project, without accessing or closing user projects.

Python compilation, desktop-file validation and whitespace checks passed.
The Debian package contains all new modules and the effects/performance guides.
Ubuntu is the tested platform; Windows packaging remains pending.
