# Bundled Malayalam Google Fonts

Noto Sans Malayalam: everyday captions. Manjari: soft, rounded text.
Anek Malayalam: bold captions and titles. These are ClipCanvas choices for video
legibility, not an objective ranking of all Malayalam typefaces.

Original font binaries, metadata and SIL Open Font License 1.1 texts are copied
unchanged from [google/fonts](https://github.com/google/fonts) at the revision
recorded in sources.json. That manifest records each source file's SHA-256.

The application registers these fonts with Fontconfig for its own process.
No network or system-wide font installation is required. Every packaged worker
uses the same files through the shared Cairo/Pango rendering module. Font
licenses permit distribution in the application and commercial video use.
